# 성인 출생연도 검증과 과거 시간대 정책

작성·조회: 2026-11-03. 연구용 정책이며 출시 지원 범위 확정이 아니다.

## 이번 결과

- 원국 검증 함수를 `validationPillars`로 분리하고 독립 표본이 있는 2000·2024년만 허용한다. 기존 `pillars2024`는 범위를 유지한다.
- [KASI 2000년 월력요항 발표](https://www.kasi.re.kr/kor/publication/post/newsMaterial/2008)의 양력 월초 일진 12개와 음력 월 시작일 12개를 대조했다. 일진은 00시·23시에서 확인하고 날짜 변환은 양방향으로 확인했다.
- 같은 자료의 한국 표준시 입춘 분 표기와 엔진 변환값 차이가 60초 미만이며, 전후 1분에서 연주·월주가 선택 기준대로 바뀌는 것을 확인했다. 이는 초 단위 경계의 독립 검증은 아니다.
- 신규 15개, 전체 86개 테스트 통과. 재현은 `tools/calculation`에서 `npm test`. Node v24.19.0, 내장 tzdb 2026b에서 실행했다.

2000년 자료에는 제3자 양여와 다른 영리 업무 이용에 대한 허락 조건이 명시되어 있다. 이번 파일은 내부 검증용으로 취급하고 서비스·공개 데이터 배포 대상에서 제외한다. 상용 사용을 위한 권리 확인은 미완료이며 이번 대조를 데이터 라이선스 승인으로 해석하지 않는다.

## 역사적 시간대 조사

[IANA tzdb의 asia 원본](https://github.com/eggert/tz/blob/main/asia)의 `Asia/Seoul`과 `Rule ROK`를 조사했다. 이 자료 자체도 권위 있는 법적 원본은 아니라고 명시한다. 법령 원문 대조는 추가 과제다.

| 구간·전환 | 조사 결과 | 현재 정책 |
|---|---|---|
| 1908년 이전 | 지역 평균시 기록 | 지원 제외 |
| 1908·1912년 | 표준 오프셋 변경 기록 | 지원 제외 |
| 1954년 | UTC+9에서 UTC+8:30 전환 | 지원 제외 |
| 1961년 | UTC+8:30에서 UTC+9 전환 | 지원 제외 |
| 1948~1960년 일부 | 서머타임 규칙 존재 | 지원 제외 |
| 1987·1988년 | 5월 시작·10월 종료 서머타임 | 지원 제외 |
| 2000년 | 독립 날짜·일진·입춘 표본 검증 | 연구 입력만 허용 |
| 다른 성인 출생연도 | 독립 원국 표본 미확보 | 연구 원국 함수에서 거절 |

Node `Intl`의 서울 오프셋을 tzdb 규칙과 대조해 1954·1961년 변경과 1987·1988년 서머타임 시작·종료의 직전·직후 총 12개 순간이 일치함을 확인했다. 이는 UTC 순간에서 현지 시각으로 변환하는 런타임 검사다. 현지 출생 시각을 UTC로 되돌릴 때의 모호성 해결이나 역사적 사주 정확도 통과를 의미하지 않는다.

## 지원 확대 조건

1. 공개·상용 이용 가능한 독립 달력·절기·일진 자료를 연도별로 확보하고 출처·버전을 고정한다. 특정 연도 표본 통과를 그 사이 모든 연도의 통과로 확대하지 않는다.
2. 현지 시각→UTC 변환에서 존재하지 않는 시각은 거절하고 반복되는 시각은 두 후보를 반환해 사용자 확인 또는 시간 기반 해석 제한으로 처리한다. 현재는 역사적 연도 전체를 거절하므로 임의 후보 선택은 없다.
3. 시간 모름에는 하루의 모든 가능한 순간을 고려한다. 서머타임 전환일을 단순한 24시간으로 가정하지 않는다.
4. 연주·월주는 천문 순간, 일주·시주는 명시한 현지 민간시/표준시 정책을 각각 적용한다. 서머타임을 시주에 적용하는 방식은 별도 기준 검수 후 확정한다.
5. tzdb 버전과 계산 정책·엔진 버전을 스냅샷에 포함하고 구매 결과를 소급 변경하지 않는다.

다음 작업은 자료 이용 조건을 해결한 독립 성인 연도 표본 확대와 12시지·시주 정책 검증이다. 성인 서비스의 유료 출시는 충분한 출생연도 범위 검증 후 판단한다.
