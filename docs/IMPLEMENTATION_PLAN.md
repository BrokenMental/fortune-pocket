# 구현 순서와 완료 기준

설계: [DESIGN.md](DESIGN.md). 현재 설계와 계산 검증 전용 코드가 있으며 서비스 구현은 아직 시작하지 않았다.

## 단계 1 — 계산·콘텐츠·원가 검증

해석 연결 후속: [출처가 있는 전통 오행 분류와 자체 편집 질문](TRADITIONAL_INTERPRETATION.md)을 실제 일간 계산에 연결했다. 전체 169개 통과. 성격 확정·전체 원국 해석은 미구현이며 다음은 모바일 결과 화면 연결이다.

실제 계산 연결: [2000년 성인 입력→궁합 카드](CALCULATED_PRODUCT.md) 구현. 준비4/계산97/콘텐츠64, 총 165개 통과. 계산 사실 설명 단계이며 전통 성향 해석 근거표와 상용 지원 범위는 남아 있다. 추가 모의 평가 보고서보다 계산/해석 연결을 우선한다.

공급사 통합 후속: [모의 전송·계수·영속 복구](PROVIDER_PIPELINE.md) 연결. 준비4/계산97/콘텐츠59, 총 160개 통과. 실제 네트워크·모델·원가 측정은 미실행이다.

공급사 계약 후속: [OpenAI 모의 어댑터·토큰 계수](OPENAI_ADAPTER_CONTRACT.md) 구현. 준비 4·계산 97·콘텐츠 54, 전체 155개 통과. 실제 네트워크 전송·API 계수·계정 검증은 미실행이다.

공통 검증 후속: [루트 검증·API 준비 점검](PROJECT_CHECKS.md) 구현. 준비 4·계산 97·콘텐츠 50, 총 151개 통과. 실제 API 평가는 모델·예산 기록·키·어댑터·토큰 계산기가 없어 비활성 상태다.

통합 후속: [복구·타임아웃·콘텐츠 검사](INTEGRATED_RECOVERY.md) 연결, 콘텐츠 50개 통과·합성 샘플 6개 실행/재사용 확인. 실제 공급사 연결·토큰 계산·청구 조회는 미완료다.

복구 후속: [요청 해시·저장 응답 재개](RECOVERABLE_EXECUTION.md) 구현, 콘텐츠 총 46개 통과. 중단 후 저장 응답 정산과 중복 전송 차단을 모의 확인했다. 타임아웃·콘텐츠 검사와 복구 흐름의 통합은 다음 작업이다.

대사 후속: [호출 식별·모델/단가·사용량 대사](CALL_RECONCILIATION.md) 구현, 콘텐츠 총 41개 통과. 실제 공급사 조회와 요청/응답 영속 복구는 미완료다.

영속 장부 후속: [파일 예산 장부](FILE_BUDGET_LEDGER.md)와 제어기 연결 구현, 콘텐츠 총 37개 통과. 미확인 예약 복구·동시 열기/손상/저장 실패 차단 확인. 외부 호출 ID·모델/단가 스냅샷·대사는 다음 과제다.

실행 제어 후속: [로컬 예산 제어기](BUDGET_CONTROLLER.md) 구현. 모의 예약·정산·타임아웃·재시도·동시 호출 검사 포함 콘텐츠 총 31개 통과. 영속 장부와 실제 공급사 연결은 미완료다.

현재 상태의 기준: [미완료 항목·모델 후보·실제 평가 실행안](EVALUATION_EXECUTION_PLAN.md). 아래 진행 기록은 각 작업 당시 이력이며 최신 결과와 구분한다. 다음 구현은 유료 호출 없는 예산 예약·실행 제어기다.

수정 후속: [별칭 분리·회고 공개 문안](EDITORIAL_REVISION.md) 적용 및 새 실행/재검토 기록, 콘텐츠 총 25개 통과. 회고는 소유자 전용 가상 샘플 범위 통과, 선물책의 계산 근거 미연결은 계속 보류다.

편집 검토 후속: [6개 결과 자체 검토와 이력](EDITORIAL_REVIEW_RESULTS.md) 기록, 콘텐츠 총 22개 테스트 통과. 별칭 표시 분리·회고 공개 문안 수정과 계산 근거 연결이 남아 있어 제공 판정은 보류한다.

로컬 실행 후속: [샘플 실행기](LOCAL_CONTENT_RUNNER.md)로 6개 고정 응답을 검토 대기까지 연결하고 파일 저장 확인. 콘텐츠 테스트 총 20개 통과. 실제 모델·120개 생성·비용 측정은 미진행이다.

생성 준비 후속: [요청 계약·평가 기록](GENERATION_REQUEST_AND_EVALUATION.md) 구현, 콘텐츠 테스트 15개 통과. 평가 120행은 생성 대기이며 공급사 연결·실측은 미진행이다.

최신 콘텐츠 후속: [샘플 JSON·오류 사례](CONTENT_SAMPLE_VALIDATION.md) 작성, 콘텐츠 테스트 10개 통과. 샘플 6개 구조화, 공유 개인정보 보조 차단 추가. 실제 모델 주입 방어·120개 생성 평가는 미실행이다.

콘텐츠 후속: [출력 계약·평가 입력](CONTENT_CONTRACT.md)과 검증 코드 작성. 가상 입력 120개(상품별 20개) 준비, 콘텐츠 검사 5개 통과. 120개 생성·평가 및 원가 측정은 미실행이다.

콘텐츠 진행: [가상 상품 샘플 6종](PRODUCT_SAMPLES.md)과 [평가 기준](CONTENT_EVALUATION.md) 작성 완료. 분량·문안 검토용이며 계산 기반 개인화, 상품별 20개 평가, 이미지/PDF 기능 및 비용 실측은 미완료다.

최신 후속: [자료 이용 조건·시주 정책 검증](DATA_RIGHTS_AND_HOUR_POLICY.md)까지 총 97개 테스트 통과. 자료 권리·독립 시주 검수·성인 연도 전반 검증은 미확정이다. 가상 상품 샘플 제작은 병행 가능하다.

진행: [날짜·절기·원국 검증](CALCULATION_VALIDATION.md)과 [2000년 성인 표본·역사적 시간대 정책](HISTORICAL_TIME_POLICY.md)을 정리해 전체 86개 테스트 통과. 독립 자료의 상용 이용 조건, 성인 연도 전반 확대, 독립 시주 검수와 엔진 최종 선정은 남아 있다.

- 계산 엔진 후보의 라이선스, 양음력·윤달·절기 경계 처리 검토.
- 해석 기준을 고정하고 독립된 기준값과 계산 결과 대조.
- 세 영역의 500원/1,000원 상품 샘플을 모두 제작.
- 상품별 최소 20개 가상 프로필로 한국어 품질, 반복 문구, 비용, 지연 측정.
- AI 원가가 목표를 넘으면 길이·모델·템플릿을 조정. 품질을 유지할 수 없으면 해당 상품 보류.
- 완료 기준: 계산 경계 오류 해결, 상품 범위 명확, 실제 비용표 작성.

## 단계 2 — 모바일 화면과 구매 전 경험

- 홈, 상품 상세, 프로필, 궁합, 선물, 일기, 보관함 화면.
- 가상 결과를 사용해 입력부터 결과까지 시연.
- 500원 직접 결제와 1,000원 직접 결제 흐름을 확인. 충전 유도 없음.
- 완료 기준: 모바일에서 가격·제공 범위·입력 오류·시간 모름·무료 예시를 이해할 수 있음.

## 단계 3 — 계정·결제·생성 공통 기반

- 인증, 소유권 검사, 주문 스냅샷, 결제 테스트 환경, 작업 큐, 결과 저장.
- 궁합 → 선물 → 일기 회고 순으로 같은 주문·결과 기반 연결.
- 완료 기준: 세 영역 모두 테스트 결제로 구매하고 재열람 가능.

## 단계 4 — 공유·선물·운영 복구

- 카드 이미지/PDF, 만료 공유, 공유 철회, 상대방 입력 초대.
- 생성 실패 자동 복구, 환불 큐, 주문 대사, 비용 경보.
- 완료 기준: 결과 미제공 결제를 방치하지 않고 복구/환불 상태를 추적 가능.

## 단계 5 — 출시 점검과 소규모 유료 실험

- PG 계약·정책·업종 심사, 약관·개인정보 문구, 지원 창구 확정.
- 운영 결제로 500원/1,000원 승인·실패·환불을 각각 검증.
- 세 영역을 제공하되 대표 유입 상품은 궁합 하나로 시작.
- 유료 30건에서 결제 마찰·생성 원가·오류·공유를 점검. 매출 보장 또는 시장 검증 완료로 해석하지 않음.

## 필수 기능 테스트

| 상황 | 기대 결과 |
|---|---|
| 클라이언트가 1,000원을 500원으로 변조 | 승인 거절 |
| 다른 사용자 주문/일기 ID 접근 | 접근 거절 |
| 승인 후 네트워크 단절 | 조회로 주문 복원, 중복 결제 없음 |
| 웹훅 반복·역순 전달 | 단일 주문·단일 작업, 최종 상태 유지 |
| 워커 작업 중 프로세스 종료 | 잠금 만료 후 재처리, 중복 결과 없음 |
| AI 스키마 오류·타임아웃 | 제한 재시도 후 환불 경로 |
| 환불과 생성 완료 동시 발생 | 환불 우선, 결과 전달 중지 |
| PG 취소 장애 | 환불 대기 표시와 운영 재시도 |
| 공유 철회·만료 | 원본·이미지 URL 접근 차단 또는 짧은 서명 URL 만료 |
| 일기에 지시문·스크립트 입력 | 지침 변경·HTML 실행 없음 |
| 프로필 수정 후 이전 결과 조회 | 구매 시점 결과 유지 |
| 입력 시간 모름·윤달·절기 경계 | 기준에 맞는 계산, 불확실성 표시 |
| 무료 일기 저장·열람 | 결제 없이 가능 |
| 사용자 삭제 요청 | 공유 즉시 철회, 콘텐츠·보존 대상 분리 처리 |

## 다음 작업의 시작점

코딩을 시작한다면 단계 1의 달력 엔진 검증과 상품 샘플을 먼저 만든다. 원가와 계산 품질이 확인되기 전에 결제 가능한 운세 서비스를 공개하지 않는다.
