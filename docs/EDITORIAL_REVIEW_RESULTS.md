# 샘플 자체 편집 검토와 이력

작성·검토: 2026-11-03. 검토자: Codex, 기존 문안 작성 에이전트의 자체 검토. 독립 전문가 또는 사용자 검수가 아니다.

## 결과

원본 실행 `fa63342e-94a3-44ca-8e7e-1d387a956231`의 6개 JSON을 검토했다. 문안은 보존하고 6건 모두 제공 전 보완이 필요한 reject 판정으로 기록했다. 이는 콘텐츠 형식 테스트 실패가 아니라 의미·공개 범위에 대한 검토 판정이다.

각 항목의 언어·유용성·반복 판정은 이번 6개만 비교한 자체 편집 판단이다. 120개 결과의 다양성 평가나 가격 가치 검증이 아니다. 이번에는 수정 요청을 남겼으며 문안 수정본을 생성하거나 원고를 바꾸지는 않았다. 회고의 기록 기반 요약은 소유자 전용으로 유지할 수 있지만 현재 공유 함수에는 별도 공개용 결과가 없어 공유 연결을 보류한다.

## 보존 방식

`tools/content/review-log.mjs`의 saveReview는 실행 보고서에서 검토 대기 행을 찾아 실제 결과 파일을 읽고 SHA-256을 기록한다. 결과 경로의 실행 디렉터리 이탈과 상품 불일치를 거절한다. 판단은 기존 recordReview 완료 조건을 적용한다.

검토는 실행 폴더의 `reviews/<UUID>.json`에 새 파일로 저장한다. 원본 report.json·응답·120개 평가 대기 기록을 바꾸지 않는다. 후속 검토는 previousReview로 이전 이벤트를 연결하고 같은 사례·원본 해시인지 검사한다. 원본 내용이 달라지면 새 실행을 만들고 이전 결과를 보존한다. 실제 수정본의 실행 간 연결은 후속 구현 대상이다.

이 방식은 로컬 파일 기록이며 암호학적 서명·사용자 인증·변조 방지 저장소를 제공하지 않는다. 경로 검사는 문자열 기준이고 악의적인 심볼릭 링크를 사용하는 비신뢰 실행 폴더용으로 설계하지 않았다.

실행한 명령: `tools/content`에서 `node editorial-review.mjs runs/fa63342e-94a3-44ca-8e7e-1d387a956231`. 같은 명령을 다시 실행하면 새 이벤트가 생기므로 단순 확인을 위해 재실행하지 않는다.
