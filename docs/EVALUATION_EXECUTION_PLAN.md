# 실제 평가 준비 현황과 실행안

작성·공식 자료 조회: 2026-11-03. 상태: 실행 제안. 유료 호출 예산 승인·API 연결·실제 생성은 아직 없다.

## 현재 결과와 남은 조건

| 영역 | 완료 | 남은 조건 |
|---|---|---|
| 계산 | 날짜·절기·원국 연구 검사 97개 | 성인 연도 전반, 독립 시주 검수, 자료 이용 조건, 제품 지원 범위 |
| 문안 | 가상 상품 6종과 JSON | 실제 계산 근거 연결·독립 품질 검수 |
| 공개 범위 | 선물 별칭 분리·회고 직접 공유 차단 | 확인 화면·접근 제어·만료·철회·실제 공개본 검수 |
| 생성 준비 | 요청 계약·구조/보조 개인정보 검사·로컬 실행 | 공급사 어댑터·토큰 제한·비용 예약·타임아웃·재시도 |
| 평가 | 입력 120개·대기 기록·검토 이력, 콘텐츠 테스트 25개 | 실제 생성 120개·검토·반복 분석·원가/지연 측정 |
| 서비스 | 설계 | 웹 화면·인증·저장·결제·복구·운영·배포 |

계산 테스트 수와 콘텐츠 테스트 수는 별도 이력이다. 이번은 문서 정리이므로 테스트를 재실행하지 않았다. 120개 입력은 20개 상황을 상품별로 배정한 것이며 모두 생성 대기다.

## 1차 모델 후보

이번 비교는 짧은 한국어 카드의 구조 준수와 비용을 확인할 OpenAI 내부 두 후보로 한정한다. 전체 공급사 비교나 한국어 품질 우열 판정은 아니다.

| 후보 | 문서상 입력/출력 단가, 100만 토큰당 USD | 실험 역할 |
|---|---|---|
| GPT-5.4 mini | 0.75 / 4.50 | 문안 생성의 기준 후보 |
| GPT-5.4 nano | 0.20 / 1.25 | 비용 절감 후보, 동일 입력으로 품질 하락 여부 비교 |

근거: [mini 공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-5.4-mini), [nano 공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-5.4-nano). 두 문서는 Responses API와 Structured Outputs 지원을 표시한다. 캐시·Batch 할인은 예산에 적용하지 않는다. 지역 처리 추가 비용·세금·환전은 아래 USD 추정에 포함하지 않는다.

계정별 접근 가능 여부와 최신 지원 종료 상태는 실제 실행 직전에 재확인한다. nano 페이지의 스냅샷 목록에는 Deprecated 표시가 함께 있어 특정 스냅샷을 사용 가능으로 확정하지 않았다. 접근 불가·지원 종료가 확인되면 후보를 교체하고 가격/입력/계약 버전을 다시 기록한다. 모델·추론 설정·스냅샷은 평가 중 임의 변경하지 않는다.

위 역할 배정은 프로젝트의 실험 가설이다. mini가 한국어 문안을 더 잘 쓴다는 실측 결과는 아직 없다.

## 호출 예산 제안

가정: 요청당 입력 4,000토큰, 청구 출력 3,000토큰 상한. 추론 토큰 등 실제 청구 출력도 이 예산에 포함해 추적해야 한다. 글자 수 제한과 토큰 수는 별개이며 긴 카드가 잘리면 상한을 조정한 새 실험으로 처리한다.

- mini: (4,000×0.75 + 3,000×4.50)/1,000,000 = 0.0165 USD/시도.
- nano: (4,000×0.20 + 3,000×1.25)/1,000,000 = 0.00455 USD/시도.
- 사전 비교: 같은 12개 입력을 두 후보로 실행하면 최초 24시도, 모두 1회 재시도할 때 최대 48시도·0.5052 USD 가정.
- 본평가: 통과한 후보 하나로 상품별 20개·총 120개. 모두 1회 재시도할 때 최대 240시도이며 mini 기준 3.96 USD 가정.
- 사전 비교와 본평가 합계 4.4652 USD 가정. 전체 실험 예산 제안은 5 USD다. 이는 지출 승인이나 구현된 강제 상한이 아니다. 추가 비용이 확인되면 호출 전 재산정한다.

요청 전 토큰 수를 확인하고 최악의 시도 비용을 예약한다. 재시도도 새 예약으로 계산하며 실행 중 합계가 상한을 넘을 수 있으면 호출하지 않는다. 타임아웃·미확인 사용량은 0으로 처리하지 않고 예약을 유지한다. 실제 비용 추적기가 구현되기 전 유료 실행은 하지 않는다.

원화 환율은 이번에 가정하지 않는다. 실행 당시 적용 환율·결제 비용을 기록해 상품별 AI+재시도 목표 상한 40원/100원과 비교한다. 5 USD 전체 실험 예산과 상품별 원가 조건은 둘 다 충족해야 한다.

## 실행 순서와 중단 조건

1. 현재 단계의 입력은 가상이며 원국이 없다. 먼저 demo 또는 선택 가상 기록의 journal 모드로 평가한다. 실제 사주 개인화 성능 평가와 구분하고 결과에 가상 표시를 유지한다.
2. 공급사 어댑터·출력 구조·실행 예산·응답 사용량 기록을 구현하고 모의 응답으로 검증한다. 계정 접근과 전송 데이터·보관 정책 확인 후 실제 호출 범위를 정한다.
3. 후보별 동일한 12개 입력: 상품별 2개, 짧은 입력과 긴 입력/시간 모름을 포함한다. 상품·모델별 비용·지연·구조/내용 실패를 기록한다. 주입·개인정보 공격 사례는 별도 묶음으로 평가하며 정상 120개에 포함하지 않는다.
4. 개인정보 노출·원문 외 사건 단정·미허용 근거가 남으면 해당 결과를 제공하지 않는다. 예산·호출 상태 미확인 또는 통제 실패 시 실행을 중단한다.
5. 비교 후 후보 하나로 새 실행 ID의 120개 결과를 만든다. 사전 12개 결과를 재사용해 120개 완료로 섞어 세지 않는다. 최소한 각 상품 20개 모두를 검토하고 생성 실패도 기록한다.
6. 구조 통과율·최종 실패율·모델별 비용·p50/p95 지연·반복 문장과 의미 중복을 집계한다. 처리 속도는 공급사 호출 시간을 따로 측정한다. p95의 작은 표본 한계를 표시한다.
7. 필수 내용 검토를 전부 통과한 결과만 후보 합격으로 기록한다. 독립 검수·모바일 화면·원화 원가·계산 검증이 끝나기 전 상용 출시 완료로 보고하지 않는다.

## 바로 이어서 할 작업

유료 호출 없이 요청별 토큰·예산 예약과 실패/타임아웃 정산을 검사할 공급사 비종속 실행 제어기를 구현한다. 이 작업은 현재 로컬 실행기와 연결할 수 있다. 실제 모델 연결은 승인된 예산과 접근 수단이 마련된 뒤 진행한다.
