# 샘플 로컬 실행기

작성·실행: 2026-11-03. 콘텐츠 테스트 총 20개 통과.

## 실행 방법

`tools/content`에서 `npm run local`을 실행한다. 기존 샘플 6종을 고정 응답으로 재생하며 모델 호출·네트워크 접근·결제는 수행하지 않는다. 추가 패키지 설치는 필요 없다. 검사는 `npm test`다.

실행마다 `tools/content/runs/<UUID>/`에 결과 JSON과 report.json을 새로 저장한다. 기존 실행 및 120건의 evaluation.json은 덮어쓰지 않는다. runs는 Git 제외 대상이다. 실제 사용자 정보를 넣는 용도의 실행기가 아니다.

이번 실행 폴더: `tools/content/runs/fa63342e-94a3-44ca-8e7e-1d387a956231/`. 보고서 1개와 샘플 응답 6개의 존재·검토 대기 상태를 확인했다.

## 처리 흐름

1. 가상 근거와 사용자 데이터를 분리해 buildRequest로 요청을 만든다. 회고에는 원고의 실제 가상 기록 J1~J3을 전달한다. 다른 상품은 계산하지 않은 demo 모드다.
2. 고정 응답 제공자를 호출한다. 호출을 주입할 수 있어 제공자 실패와 비정상 응답을 테스트할 수 있다. 유료 모델을 실행하는 어댑터는 없다.
3. 상품·분량·근거 ID 구조 검사를 수행한다.
4. 제목·카드·질문·한계 안내의 개인정보·지시문 재노출 보조 신호를 검사한다.
5. 통과하면 pending-review로 기록한다. 구조만 true이며 개인정보·근거 의미·언어·유용성·반복 판정은 null이다. 모델·토큰·비용·지연도 null로 유지한다.

실패 상태는 request-rejected, provider-failed, structure-rejected, privacy-blocked다. 제공자 예외의 원문은 보고서에 기록하지 않으며 개인정보 신호가 나온 응답은 저장용 출력으로 반환하지 않는다. 올바른 ID를 붙인 의미 모순은 자동 승인하지 않고 검토 대기에 남긴다.

## 확인한 범위와 남은 작업

신규 테스트 5개·전체 콘텐츠 20개 통과. 여섯 샘플 재생, 요청 거절 시 제공자 미호출, 예외·비정상 응답 처리, 누출 응답 제외, 미선택 근거 거절과 의미 검토 대기를 검사했다. 계산 코드는 무변경이므로 기존 계산 테스트는 반복하지 않았다.

실제 모델의 품질·지시문 주입 저항성·원가·지연을 검증한 결과가 아니다. 재시도·유료 예산 집행·환불·운영 저장소·개인정보 완전 탐지·실사용자 인증도 구현하지 않았다. 120개 평가 입력은 생성 대기 상태로 보존했다.

다음은 이번 실행의 6개 결과에 편집 검토를 기록하고, 거절·수정 이력을 보존하는 로컬 검토 절차를 연결하는 것이다. 실제 모델·예산 선정과 120개 생성 평가는 이후 진행한다.
