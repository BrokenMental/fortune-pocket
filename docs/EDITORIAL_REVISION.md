# 별칭·회고 공개 문안 수정

작성: 2026-11-03. 콘텐츠 테스트 총 25개 통과. 실제 모델·계산·비용 검증은 이번 범위에 없다.

## 수정 사항

- 선물책 첫 페이지 제목을 '생일에 보내는 한 조각'으로 바꿨다. 별칭 '솔'은 생성 content에서 제거하고 display.recipientNickname에 둔다. 사용자 메시지도 기존처럼 별도다. 실제 화면의 별칭 삽입은 아직 미구현이다.
- 회고 소유자용 결과에는 선택 기록 근거와 요약을 유지한다. publicCards는 JOURNAL_REVIEW의 직접 공유를 항상 거절한다.
- journal-share.mjs에 개인 기록과 무관한 일반 질문 3장을 작성했다. 명시적 confirmed와 카드 선택이 있어야 복사본을 반환한다. 소유자 원문·기록 요약·근거 ID를 이 문안 생성에 사용하지 않는다.
- 일반 질문은 개인화 회고 결과를 공유하는 기능이 아니다. 사용자가 이 차이를 이해하고 확인하는 화면, 인증·소유권·만료·철회는 후속 구현 대상이다. confirmed 인자 자체가 이용자의 동의 기록이나 권한 증명은 아니다.

## 새 실행과 재검토

새 실행: `tools/content/runs/05ac94c0-7cdc-457f-97d3-40bd5630b627/`.

기존 실행 fa63342e-94a3-44ca-8e7e-1d387a956231은 그대로 보존했다. 새 폴더에는 6개 샘플과 보고서 외에 revision-links.json, journal-public-copy.json, 두 재검토 이벤트를 저장했다. 연결 파일은 이전 검토·이전 원본 SHA-256과 새 검토·새 원본 SHA-256을 기록한다. 기록 전 이전 해시가 실제 파일과 같은지 확인했다.

재검토자는 Codex 작성 에이전트다. 회고는 소유자 전용 가상 샘플 범위에서 통과했다. 선물책은 별칭 수정 해결을 기록했지만 계산 근거 미연결로 reject를 유지했다. 나머지 4개 샘플의 과거 거절 사항은 해결했다고 처리하지 않았으며 새 실행에서는 검토 대기다. 이번 판정을 독립 검수·상용 출시 승인으로 해석하지 않는다.

재현: `tools/content`에서 `npm run samples`, `npm run local`, `npm test`. review-revision.mjs는 이번 이전 검토 ID에 맞춘 일회성 기록 도구다. 이미 생성된 새 폴더에 재실행하면 배타적 파일 쓰기가 거절되므로 새 실행을 사용한다. 재실행 중 일부 새 검토 파일이 생길 수 있으며 트랜잭션 저장소는 아니다.

## 검사와 다음 작업

신규 3개 포함 전체 25개 통과: 회고 직접 공유 차단, 일반 공개 질문의 확인·선택·복사 격리, 선물 content의 별칭 부재와 별도 표시 데이터 유지. 기존 콘텐츠 회귀도 통과했다. 계산 코드는 무변경으로 반복 검사하지 않았다.
