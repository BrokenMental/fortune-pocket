# 실제 입력 계산과 상품 문안 연결

작성·실행: 2026-11-03. 단순 모의 AI 응답을 재생하는 흐름에서 벗어나 생년월일을 계산하고 그 값으로 상품 문안을 구성했다. 외부 모델 호출은 없다.

최신 후속: [전통 오행 분류·자기 탐색 문안](TRADITIONAL_INTERPRETATION.md)을 v2에 연결했다. 아래 v1의 전통 분류 미연결 표기는 당시 이력이다.

## 구현 범위

`tools/content/calculated-match.mjs`는 한국 출생·2000년 입력 두 개를 양음력 정규화→원국 연구 계산→근거 목록→계산 모드 요청→MATCH_MINI 카드 3장·질문 2개로 연결한다. 상품 출력은 기존 구조 검사를 통과해야 반환한다.

입력 스냅샷·해시, 계산 버전 research-2000-kst-midnight-v1, 계산 사실, 근거 ID, 콘텐츠 버전 calculated-match-v1을 함께 남긴다. 외부에서 원국을 직접 주입하는 필드는 거절한다. birth hour는 숫자 또는 null을 명시해야 한다. 음력에는 윤달 여부가 필수다. 정규화된 양력 연도도 2000년인지 검사한다.

이는 기존에 일부 표본 검증한 연구 연도에 제한한 연결이다. 2000년 전체 날짜의 독립 검수 완료나 일반 성인 전 연도 지원을 뜻하지 않는다. 2024년은 미성년자 입력이므로 이번 성인 상품 연결에서 거절한다. 실제 고객 정보를 쓰지 않았다.

## 해석의 현재 수준

현재 문안은 계산 사실을 설명하고 대화 질문으로 연결하는 규칙형 초안이다. 일주 하나로 성격을 단정하거나 합충·오행 관계를 임의 해석하지 않는다. 전통 명리 기반의 구체적인 성향 해석·유료 상품 가치 검증까지 완료한 것은 아니다. 결과 상태는 pending-review다.

다음은 계산 사실과 전통 해석 규칙을 분리한 근거표를 만들고, 검증 가능한 해석만 문안에 연결하는 작업이다. 일간·월령·관계 규칙의 출처와 적용 한계를 확인한 뒤 사용자에게 의미 있는 해석을 보강한다. 실제 모델이 필요하면 확정 근거만 입력으로 제공하며 호출 예산을 별도로 정한다.

출생 정보는 상세 연구 JSON에만 남고 모델용 요청의 근거 목록에는 원본 날짜가 없다. 이번 결과를 실제 공개 공유에 연결하지 않았으며 기존 계산 자료의 이용 조건·성인 연도 확대 과제는 유지한다.
