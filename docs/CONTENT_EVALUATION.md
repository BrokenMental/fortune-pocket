# 샘플 평가와 다음 제작 기준

작성: 2026-11-03. 대상: [상품 샘플 6종](PRODUCT_SAMPLES.md).

후속: [콘텐츠 출력 계약](CONTENT_CONTRACT.md)과 가상 입력 120개를 준비했다. 아래 20개 결과 평가는 여전히 미실행이다.

## 이번 편집 점검

| 상품 | 설계 분량 | 이번 작성 | 판정 |
|---|---|---|---|
| MATCH_MINI | 카드 3·질문 2 | 3·2 | 분량 일치 |
| MATCH_FULL | 카드 6·질문 5 | 6·5 | 분량 일치 |
| GIFT_MINI | 해석 1·직접 메시지 | 1·1 | 문안 작성, 이미지 저장 미구현 |
| GIFT_BOOK | 4페이지·메시지 | 4·1 | 문안 작성, PDF·공유 미구현 |
| JOURNAL_PROMPT | 질문 5·짧은 해석 | 5·1 | 분량 일치, 계산 개인화 미연결 |
| JOURNAL_REVIEW | 최대 7기록의 회고 | 선택 3기록·카드 3 | 근거 J1~J3 연결 |

문안 작성자가 설계와 대조한 편집 점검이다. 독립 평가자가 검수하거나 실제 사용자에게 가격 가치를 확인한 결과가 아니다. 원국을 사용하지 않았으므로 계산 근거에 대한 평가는 보류했다.

## 다음 평가 묶음

상품별 최소 20개, 총 120개 결과를 별도로 평가한다. 현재는 상품별 예시 1개씩이며 20개 평가를 완료한 것으로 집계하지 않는다.

- 궁합: 성인 친구·연인, 선호가 비슷하거나 다른 경우, 두 사람 중 시간 모름, 절기 경계 불확실성 등을 포함한다. 관계 유형만 바꾼 같은 문안 반복을 확인한다.
- 선물: 생일·응원·새해 등 상황과 짧거나 긴 작성 메시지, 별칭 길이 차이, 시간 모름을 포함한다. 정보가 없으면 개인화 해석을 만들어내지 않는지 검사한다.
- 질문팩: 시작·휴식·관계·생활 정리 주제를 나누고 구체적으로 답할 수 있는지 확인한다. 사주 기반 개인화는 근거 검증 후 평가한다.
- 회고: 1·3·7개 기록, 반복 주제·서로 다른 주제·반대되는 기록을 포함한다. 기록 0개는 구매 차단 검사용이며 정상 결과 20개에 포함하지 않는다. 지시문·스크립트가 있는 기록도 별도 실패 사례로 검사한다.

## 항목과 판정 기준안

| 항목 | 통과 조건 |
|---|---|
| 제공 범위 | 상품별 카드·질문·페이지 수 충족 |
| 근거 | 해석은 검증한 계산 사실, 회고는 선택 기록에 추적 가능 |
| 표현 | 이해하기 쉬운 한국어, 모호한 공통 문구만으로 구성하지 않음 |
| 행동·질문 | 사용자가 실제로 답하거나 시도할 수 있음 |
| 개인정보 | 원본 출생 정보·비공개 일기·식별정보가 공유본에 없음 |
| 내용 경계 | 미래·질병·속마음 단정, 공포를 통한 추가 결제 유도 없음 |
| 반복 | 같은 상품의 다른 결과와 반복 문장을 집계하고 의미 중복을 별도 검토 |
| 가격 차이 | 긴 문장 추가 외에 제공 범위·사용 목적의 차이가 설명됨 |
| 모바일 | 실제 화면에서 잘림·넘침·읽기 부담을 확인 |
| 원가·지연 | 실측 토큰·재시도·비용·응답시간 기록, 목표 상한과 비교 |

후보 결과마다 상품 ID, 가상 입력 ID, 계산/콘텐츠 버전, 근거 ID, 검토자, 판정·수정 이유를 남긴다. 결과별 원가·지연은 미측정 값을 0으로 채우지 않고 null로 둔다. 500원 상품 40원·1,000원 상품 100원의 AI+재시도 비용 상한은 설계 목표이며 실측값이 아니다.

다음 실행은 20개 가상 입력의 구체적 목록과 공급사 비종속 콘텐츠 스키마·검증 규칙 작성이다. 실제 모델 선택·유료 호출은 별도 예산을 정한 뒤 진행한다.
