# 공통 검증과 API 평가 준비 점검

작성·실행: 2026-11-03.

## 명령

프로젝트 루트에서 `npm run check` 또는 `npm test`로 준비 상태·계산·콘텐츠 테스트를 순서대로 실행한다. 하위 패키지의 실제 테스트 목록을 읽어 Node를 직접 실행하며 셸 문자열 실행은 사용하지 않는다. 각 묶음은 최대 60초이고 실패하면 전체 종료 코드가 실패가 된다.

`npm run readiness`는 테스트 없이 로컬 설정과 입력 목록을 읽는다. 파일을 변경하거나 네트워크 요청·API 호출을 하지 않는다. 점검 자체가 정상 실행됐지만 준비가 부족한 경우 종료 코드는 0이며 blocked 목록에 부족한 항목을 표시한다. 설정을 읽을 수 없으면 실패한다. 공통 검증 통과가 실제 API 실행 허가를 의미하지 않는다.

계산 패키지는 기존 잠금 파일 기준 의존성이 필요하다. 새 환경에서는 `tools/calculation`에서 `npm ci --ignore-scripts --no-audit --no-fund` 후 루트 검증을 실행한다. 루트와 콘텐츠 도구에는 추가 외부 패키지가 없다.

실제 API 평가의 부족 항목은 모델 미선택, 예산 승인 참조 미기록, 키 미설정, 공급사 어댑터 미구현, 실제 공급사 토큰 계산기 미구현이다. 개인정보·계산 자료 권리·상용 출시 조건까지 자동 검사한 결과가 아니다.

## 설정과 비밀값

evaluation.config.json에는 비밀값을 넣지 않는다. 기본값은 enabled=false, 모델·예산·예산 승인 참조 null이다. 입력/출력 토큰 상한은 제안값 4,000/3,000이다. budgetAuthorizationReference는 실제 사용자 합의의 추적값을 넣을 자리이며 단순 문자열을 채웠다고 승인이 생기는 것은 아니다.

점검은 FORTUNE_PROVIDER_API_KEY 환경 변수의 비어 있지 않음만 확인하고 값은 출력하지 않는다. 이 변수는 아직 실제 공급사 SDK에 연결되지 않았다. 키의 유효성·계정 접근·결제 상태를 확인하지 않으며 확인을 위해 API를 호출하지도 않는다.

모델명·예산 승인 참조 등 설정값도 보고서에는 넣지 않고 항목별 ready/blocked만 표시한다. 어댑터·토큰 계산기가 없는 상태는 설정으로 우회할 수 없다. executionAllowed는 현재 항상 false다. 실행 플래그를 true로 바꾸면 안전한 비활성 기본 상태 검사에서 blocked가 된다.
